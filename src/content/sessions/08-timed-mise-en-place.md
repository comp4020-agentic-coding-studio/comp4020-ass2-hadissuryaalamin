This week's lecture is taught by a visiting chef; this session is where the
class runs a small version of the same problem. Nothing is cooked here
either — the exercise is about the order and the timing of preparation, not
about what happens once heat is involved.

## Before the session

Read the guest lecture's three categories again: work finished to
completion well ahead of time because its quality does not depend on
freshness; work brought to a stable, held state and kept there until
called; and work deliberately left undone until the last possible moment
because any earlier finishing point would cost it more than the wait does.
Bring a guess, in writing, at which category each item on the task sheet
belongs to — the guess is checked, not marked.

## In the session

**Sort.** A list of preparation tasks for a fixed, hypothetical service is
distributed. Working alone, sort each task into one of the guest's three
categories and note why. This step is compared against the group's answers
before anyone touches an ingredient, because most disagreements happen here,
not at the bench.

**Run.** A timer starts. The class executes the "before doors open" and
"held" portions of the sheet — the parts that can be done without a ticket
arriving — inside a stated allowance. The "made to order" portion is
described but not executed, since nothing is served or cooked this week;
the point is whether the earlier categories were sorted and finished in
time to make the later ones possible at all.

**Debrief.** Actual time is compared against the plan drawn up before the
run started. Where the two diverge, the question is not whether the plan
was wrong but which single step ran long, and whether that step belonged
in a different category from the one it was given.

## Why this sits where it does

Week 1 argued that most of the time in feeding oneself is spent before any
heat is applied, using real figures for how people actually spend it. This
session does not add a new figure; it takes the same argument into a
setting with a clock running, and asks a class to make the sorting decision
the guest lecture described, under a version of the same pressure, without
yet doing the cooking that decision is ultimately in service of.
