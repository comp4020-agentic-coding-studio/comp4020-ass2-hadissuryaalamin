# Task 003 — week 6 (lane B, step 1): `.compare` child-count check

- Read `src/decks/theme.css`'s `.compare` rules directly (confirmed
  unchanged from the epic-decomposition note): `.compare` is `display:
  flex; justify-content: center; gap: 2rem`, each `figure` is `flex: 1 1
  0; max-width: 44%`.
- Flexbox analysis: `flex: 1 1 0` distributes available space equally
  among children by flex-grow before the `max-width: 44%` cap can bind.
  At 2 children, equal division is 50%, which exceeds the 44% cap and so
  the cap is what actually constrains width (explaining the class's own
  "too small to compare two specimens in" comment history). At 3
  children, equal division is 33%, which is already under the 44% cap —
  so the cap never engages and 3 children should lay out cleanly with no
  CSS change.
