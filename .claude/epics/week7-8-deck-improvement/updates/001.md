## Before-fix screenshot verification (bug confirmed)

Script: `.claude/epics/week7-8-deck-improvement/updates/screenshot_bg.py`
(copied unmodified from weeks34's own script — same method: reports the
resolved `.slide-bg` `background-image` URL plus any `pageerror`/console
errors, and screenshots the slide).

All five directives confirmed broken, each producing a console 404 for the
resolved asset URL:

| File | Slide | Console evidence | Screenshot |
|---|---|---|---|
| week-07 title | `chefs-knife.jpg` | resolved request: `.../decks/week-07/assets/week-07/chefs-knife.jpg` — 404 | `screenshots/before-week07-title.png` |
| week-07 mid-deck | `knife-set.jpg` | 404 (script's reported `.slide-bg` URL reflects the still-mounted title element, same artifact weeks34 noted — the 404 console evidence and screenshot are the reliable signal) | `screenshots/before-week07-knifeset.png` |
| week-07 mid-deck | `sharpening-stone.jpg` | 404, same artifact | `screenshots/before-week07-sharpening.png` |
| week-08 title | `restaurant-kitchen.jpg` | resolved request: `.../decks/week-08/assets/week-08/restaurant-kitchen.jpg` — 404 | `screenshots/before-week08-title.png` |
| week-08 mid-deck | `plated-dish.jpg` | 404, same artifact | `screenshots/before-week08-plated.png` |

Same diagnosis as weeks34: the browser resolves the `![bg …]` CSS `url()`
against the served page path (`/decks/week-07/`, `/decks/week-08/`), not the
deck source file's location. All paths use forward slashes; not a Windows
path-separator artifact.

## Fix

Rewrote all five directives from `./assets/week-0N/<file>`
(deck-source-relative) to `../../src/decks/assets/week-0N/<file>`
(build-relative), matching the convention weeks34 settled on (confirmed
unchanged in the current `astro.config.ts`/build output before applying):

- `src/decks/week-07.deck.mdx` line 8: `chefs-knife.jpg`
- `src/decks/week-07.deck.mdx` line 53: `knife-set.jpg`
- `src/decks/week-07.deck.mdx` line 166: `sharpening-stone.jpg`
- `src/decks/week-08.deck.mdx` line 8: `restaurant-kitchen.jpg`
- `src/decks/week-08.deck.mdx` line 93: `plated-dish.jpg`
